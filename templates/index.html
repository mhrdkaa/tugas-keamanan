Algoritma yang Digunakan

AES-256-GCM

Enkripsi simetris dengan mode GCM (Galois/Counter Mode). Menghasilkan ciphertext, nonce, dan tag autentikasi untuk menjamin integritas data.

RSA-4096

Enkripsi asimetris dengan kunci 4096-bit. Digunakan untuk enkripsi kunci AES (key wrapping) dan tanda tangan digital pada token autentikasi.

Hybrid Encryption

RSA mengenkripsi kunci AES yang di-generate secara acak. AES mengenkripsi pesan. Menggabungkan keamanan RSA dengan kecepatan AES.

PBKDF2 + Token

Password di-hash dengan PBKDF2-SHA256 (100.000 iterasi). Token autentikasi ditandatangani secara digital dengan RSA dan berlaku selama 1 jam.

API Endpoints

Contoh penggunaan REST API

POST /api/auth/register   — Daftar user baru
POST /api/auth/login      — Login, dapatkan token
POST /api/auth/verify     — Verifikasi token
POST /api/message/send    — Kirim pesan terenkripsi
POST /api/message/decrypt — Dekripsi pesan (demo)
GET  /api/keys/public     — Ambil public key server
GET  /api/keys/private    — Ambil private key (demo)

Contoh login

curl -X POST /api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "alice", "password": "alice_secret_123"}'
